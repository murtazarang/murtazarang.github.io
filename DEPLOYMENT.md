# Website deployment and domain guide

This repository publishes Murtaza Rangwala's Jekyll website through GitHub Pages.
Cloudflare manages DNS for `murtaza.dev`, but Cloudflare account changes are performed manually by the domain owner.

## Publish the website

1. Open [the repository's Pages settings](https://github.com/murtazarang/murtaza.github.io/settings/pages).
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Push changes to the `main` branch.
4. Open [the repository's Actions page](https://github.com/murtazarang/murtaza.github.io/actions) and confirm that **Deploy Jekyll site to GitHub Pages** succeeds.
5. Confirm that `https://murtazarang.github.io` loads before configuring the custom domain.

## Verify the domain with GitHub

1. Open [GitHub Pages domain verification](https://github.com/settings/pages).
2. Add `murtaza.dev` under **Verified domains**.
3. Copy the exact TXT record name and value generated by GitHub.
4. In [Cloudflare](https://dash.cloudflare.com/), select `murtaza.dev`, open **DNS → Records**, and add the TXT record.
5. Keep the verification TXT record permanently.
6. Return to GitHub and select **Verify** after the TXT record resolves.

## Configure GitHub Pages for the custom domain

1. Open [the repository's Pages settings](https://github.com/murtazarang/murtaza.github.io/settings/pages).
2. Enter `murtaza.dev` under **Custom domain** and save it.
3. Keep the repository's root `CNAME` file set to `murtaza.dev`.

## Configure Cloudflare DNS

Add four DNS-only A records for the apex domain.

| Type | Name | Content | Proxy status | TTL |
| --- | --- | --- | --- | --- |
| A | `@` | `185.199.108.153` | DNS only | Auto |
| A | `@` | `185.199.109.153` | DNS only | Auto |
| A | `@` | `185.199.110.153` | DNS only | Auto |
| A | `@` | `185.199.111.153` | DNS only | Auto |

IPv6 support can be added with four DNS-only AAAA records.

| Type | Name | Content | Proxy status | TTL |
| --- | --- | --- | --- | --- |
| AAAA | `@` | `2606:50c0:8000::153` | DNS only | Auto |
| AAAA | `@` | `2606:50c0:8001::153` | DNS only | Auto |
| AAAA | `@` | `2606:50c0:8002::153` | DNS only | Auto |
| AAAA | `@` | `2606:50c0:8003::153` | DNS only | Auto |

Add the `www` hostname as a DNS-only CNAME record.

| Type | Name | Target | Proxy status | TTL |
| --- | --- | --- | --- | --- |
| CNAME | `www` | `murtazarang.github.io` | DNS only | Auto |

Do not include `https://`, a path, or the repository name in a DNS target.
Do not remove MX, SPF, DKIM, DMARC, domain-verification, or other unrelated records.
Do not create a wildcard DNS record for this website.

## Enable HTTPS

1. Wait for GitHub Pages to report that its DNS check and TLS certificate are ready.
2. Enable **Enforce HTTPS** in the repository's Pages settings.
3. Confirm that `https://murtaza.dev` and `https://www.murtaza.dev` resolve correctly.
4. Leave Cloudflare proxying disabled unless Cloudflare caching, WAF, or other proxy features are specifically required.
5. If Cloudflare proxying is enabled later, first set **SSL/TLS → Overview** to **Full (strict)** and confirm that GitHub HTTPS already works.
6. Never use Cloudflare **Flexible** SSL for this site.

## Verify DNS from a terminal

```sh
dig murtaza.dev +noall +answer -t A
dig murtaza.dev +noall +answer -t AAAA
dig www.murtaza.dev +noall +answer -t CNAME
dig _github-pages-challenge-murtazarang.murtaza.dev +short TXT
curl -I https://murtaza.dev
```

The apex A results should match GitHub's four published IPv4 addresses.
The `www` result should point to `murtazarang.github.io`.
The TXT result should match the exact verification value generated in GitHub settings.

## Update website content

- Edit `_config.yml` for identity, contact links, domain, and site-wide metadata.
- Edit `_data/projects.yml` for project entries.
- Edit `_data/publications.yml` for publications.
- Edit `_data/manuscripts.yml` for manuscripts in preparation.
- Edit `_data/employment.yml` and `_data/education.yml` for CV entries.
- Edit `_data/highlights.yml` for homepage highlight cards.
- Edit `index.html`, `research.html`, `projects.html`, `cv.html`, and `blog.html` for page structure and prose.
- Replace `images/potrait.jpg` to update the homepage profile image while preserving the filename.
- Replace the PDFs under `files/` when the résumé or academic CV changes.
